Getting started with NumPy

The Data Camp courses should have prepared you well for this exercise. This is just a quick run-through to make sure that you are on track.

One of the really cool things about NumPy is that it understands vectors and matrices, and even allows you to perform arithmetic on them. The purpose of these tasks is to familiarize you with NumPy ndarrays.

Vectors and vector operations are incredibly useful for performing sensitivity analyses (and gaining computational efficiencies), so be sure that you understand and practice using vectors. The exercises below are a good place to start.

Mixing Vectors, Matrices and Scalars

NumPy handles operations between scalars (single valued variables) and ndarrays in a very natural fashion (and consistent with the way R handles vectors and scalars). It will perform the requested operation for each value in the vector.

Here’s an example:


# Adding a scalar to an array

a = 50
x = np.array([4, 4.67])
a + x
## array([54.  , 54.67])

Observe what happens here. You will find that this ability is very useful for doing sensitivity analyses.

# multiping an array by a scalar

a * x
## array([200. , 233.5])
# exponentiating an array with a scalar

x**2

#%%
## array([16.    , 21.8089])
# dividing an array by a scalar
x / 2
## array([2.   , 2.335])
# Calculating the product of a matrix and a vector (i.e. a 1D array)

b = np.array([4, 3])
A = np.array([[14, 6],
              [7, 12]])
b.dot(A)
## array([77, 60])

Sensitivity Analysis

Now we’re going to take advantage of NumPy’s capabilities to perform a sensitivity analysis. The EOQ is a popular inventory management model. You learned/will learn more about this in Foundations of Operations Management (BUS 361) and Supply Chain Management (BUS 453).

The key equations you’ll need are for the

  • total relevant cost (\(TRC(Q)\))
  • annual total cost (\(ATC(Q)\))
  • the cost minimizing order quantity, i.e. the EOQ (\(Q^*\))

\[Q^* = \sqrt{\frac{2DA}{vr}},\quad\] \[TRC(Q) = \frac{Qvr}{2} + \frac{DA}{Q}\] \[ATC(Q) = TRC(Q) + Dv\]

where:

$D = $ annual demand (units)

$A = $ aggregate order placement cost

$v = $ unit acquistion cost

$r = $ unit holding cost percentage rate (as a % of unit cost).

Note: the time units for \(D\) and \(r\) must be the same.

Assuming annual demand of 10,000 units, a $$\(500\) cost to place an order, unit cost of $$\(12.95\), and an annual holding cost percentage rate of 35%, we can find the cost minimizing order quantity and its associated annual total cost.

import math
import matplotlib.pyplot as plt

# initialize parameters

D = 10000
A = 500
v = 12.95
r = 0.35

Q = np.arange(1500, 3200, 100)
Q

# Calculate the optimal order quantity
## array([1500, 1600, 1700, 1800, 1900, 2000, 2100, 2200, 2300, 2400, 2500,
##        2600, 2700, 2800, 2900, 3000, 3100])
Qstar = math.sqrt(2 * D * A / (v * r))
Qstar
## 1485.3578426001038
# Calculate vectors of costs corresponding to order quantity Qstar

ahc = Qstar * v * r / 2
aoc = (D * A) / Qstar
trc = ahc + aoc
trc
## 6732.3844215849695
atc = trc + D * v
atc
## 136232.38442158498

Now, using NumPy vector calculations and operations, we will calculate the total relevant and annual total costs for order quantities between 1000 and 2000 in 100 unit increments (np.arange will be useful here). The cost minimizing order quantity of \(1485.3578426\) yields the lowest possible total relevant cost of \(\$6732.3844216\). We can see that the quantity \(1500\), the closest value of Q for which \(TRC(Q)\) was calculated, yields the smallest cost premium for all of the order quantities.

We can use the matplotlib library to visualize the relationship between order quantity and cost. We’ll separately plot the annual holding cost \((AHC(Q))\), annual ordering cost \((AOC(Q))\), and the total relevant cost \((TRC(Q))\). This will illustrate the nature of the EOQ cost function.

# Plot EOQ Tradeoff Curves

plt.plot(Q, trcq, label='TRC(Q)')
plt.plot(Q, ahcq, label='AHC(Q)')
plt.plot(Q, aocq, label='AOC(Q')
plt.xlabel('Q')
plt.ylabel('Cost')
plt.legend()
plt.title('EOQ costs as a function of $Q$')
plt.show()

We see how easily we are able to visualize our analysis. Of the 8 statements above, half were just related to formatting; if we leave out some of the formatting statements, we still obtain a graph that facilitates visualizing the relationships.
